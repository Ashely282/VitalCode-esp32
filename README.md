# VITALCODE 

## AI Wellness Companion Robot

### Team Members
- Parthiv – Robot Development
- Apeksha – Programming & Documentation
- Sidharth – CAD & Product Design
- Manoj – Mobile/Web Application

## Problem
Many elderly people forget to take their medicines and may feel lonely.

## Solution
VITALCODE is an AI companion robot that reminds users to take medicines, displays emotions, tracks medicine history, and connects to a mobile app.

## Features
-  Cute robot emotions
-  Medicine reminders
-  Mobile app connection
-  Notifications
-  Medicine history
-  Battery monitoring

## Hardware

- Display
- Buzzer
- Battery
- Sensors
